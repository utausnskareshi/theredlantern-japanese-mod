The Red Lantern 日本語化パッチ（非公式）
========================================

Steam版「The Red Lantern」を日本語で遊べるようにする、非公式のツールです。
ゲームの開発元・販売元とは関係ありません。ご利用は自己責任でお願いします。


■ 動作環境
  ・Windows 10（バージョン1903以降）／Windows 11
  ・Steam版 The Red Lantern（Steamのビルド 20391034 で動作を確認）
  ・追加のランタイムは不要です（Windowsに標準で入っている .NET Framework 4.8 で動きます）


■ 使い方
  1. このフォルダを好きな場所に展開します（translations フォルダも一緒に置いてください）。
  2. ゲームを終了した状態で TheRedLanternJP.exe を起動します。
  3. 「日本語化する」ボタンを押します。
  4. Steamからゲームを起動すると、日本語で表示されます。

  元の英語版に戻したいときは、もう一度ツールを起動して「元に戻す」ボタンを押してください。
  パッチを当てる前とまったく同じ状態に戻ります。

  ゲームがインストールされていない場合は、その旨のメッセージを表示して終了します。

  初めて起動したときに「WindowsによってPCが保護されました」と表示された場合は「詳細情報」→「実行」を、
  「開いているファイル - セキュリティの警告」（発行元を確認できませんでした）と表示された場合は「実行」を
  押してください。このツールにはデジタル署名が無いため、インターネットから入手したファイルとして警告が
  表示されます。展開する前にZIPファイルのプロパティで「許可する」にチェックを入れておくと、表示されなくなります。


■ 何をしているか
  このゲームには、Steam版では使われていない公式の日本語訳（全体の約7割）と
  日本語フォントが、最初から同梱されています。このツールは次の2つを行います。

  ・起動時の言語を日本語に切り替える（GameAssembly.dll の5バイトを書き換え）
  ・台詞データ（TheRedLantern_v001-Built.twig）を日本語化する。変更するのは次の3つだけです。
      - 公式の日本語訳が無い行に、補完訳（translations\ja_supplement.tsv）を追記する
      - 選択肢などは、ゲームが言語の設定に関係なく「既定の文言」（英語）を表示するため、
        日本語訳のある項目は既定の文言を日本語訳にする
      - 公式訳のうち、ゲームのフォントに無い漢字を含む4か所（「□」と表示される）の語だけを、
        表示できる書き方に直す（例:「憧れ」→「あこがれ」）

  英語の訳文は変更しません。音声は英語のままです。タイトルロゴや日記の手書きの文字、
  オプション画面の見出しと「On / Off」など、ゲーム側で固定されている一部の表示も英語のままです。
  書き換える前に、ファイルが想定どおりの内容かを必ず確認します。ゲームが更新されて
  内容が変わっていた場合は、何も変更せずにお知らせします。

  バックアップは、ゲームのフォルダ内の TheRedLanternJP_backup に保存されます。
  「元に戻す」が終わると自動で削除されます。
  処理の途中でPCの電源が落ちた場合も、次に起動したときに「元に戻す」で元の状態に戻せます。


■ 補完訳を使いたくない場合
  translations フォルダ（または ja_supplement.tsv）を削除してから「日本語化する」を押すと、
  公式の日本語訳だけが有効になります。公式訳の無い行は英語のまま表示されます。
  補完訳はテキストファイルなので、訳を自分で直すこともできます
  （直したあとは、いったん「元に戻す」→ ツールを起動し直して「日本語化する」で反映されます）。
  保存するときの文字コードは UTF-8 にしてください。それ以外の文字コードで保存すると、
  文字化けを防ぐために補完訳は読み込まれず、画面の補完訳の欄に「使えません」と表示されます。
  ただし、ゲームの日本語フォントに入っていない文字は「□」と表示されます。
  使える文字の一覧と検査ツールは、下記「配布元」のリポジトリにあります。


■ うまくいかないとき
  ・「未対応のバージョン」と表示される
      ゲームが更新されたか、ファイルが変更されています。Steamのライブラリでゲームを
      右クリック →「プロパティ」→「インストール済みファイル」→「ゲームファイルの整合性を確認」
      を実行すると、ゲームを正規の状態に戻せます。
  ・ゲームのアップデート後に英語へ戻った
      アップデートでファイルが置き換わったためです。対応版のツールで適用し直してください。
  ・書き込みに失敗する
      ゲームを終了してから実行してください。それでも失敗する場合は、ツールを右クリックして
      「管理者として実行」をお試しください。
  ・「読み取り専用になっている」と表示される
      メッセージに出ているファイルを右クリック →「プロパティ」で、「読み取り専用」の
      チェックを外してください。
  ・「別の画面（またはコマンド）で処理中」と表示される
      このツールをもう1つ起動していないか確認し、そちらの処理が終わってからやり直してください。
  ・「台詞データはこのツールが書いた内容ではありません」と表示される
      日本語化した後で、ゲームの更新などにより台詞データが置き換わっています。
      「元に戻す」を押すとプログラム本体だけを戻します（台詞データには触りません）。
      その後、上の「ゲームファイルの整合性を確認」を実行してください。
  ・ログの場所
      %LOCALAPPDATA%\TheRedLanternJP\TheRedLanternJP.log（画面の「ログを開く」からも開けます）
