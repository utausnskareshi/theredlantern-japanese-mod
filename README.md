# The Red Lantern 日本語化パッチ（非公式）

Steam版 [The Red Lantern](https://store.steampowered.com/app/1053710/The_Red_Lantern/) を日本語で遊べるようにする、非公式のパッチツールです。
ゲームの開発元（Timberline Studio）・販売元（Kepler Interactive）とは関係ありません。

*An unofficial Japanese localization patcher for the Steam version of The Red Lantern. It switches on the official Japanese text and font that already ship (unused) inside the PC build, and fills the untranslated lines with a fan translation. The tool contains no game code, assets, fonts or original text.*

## できること

- ボタン1つで日本語化し、同じボタンで**パッチを当てる前とまったく同じ状態**に戻せます。
- ゲームに同梱されている公式の日本語訳（3,449行）を有効にします。
- 公式訳の無い行（ジャーナル・目標・通知・チュートリアルと一部の台詞、1,517行）には補完訳を追記します。
- 選択肢など、そのままでは日本語訳があっても英語で表示されてしまう文言も、日本語で表示されるようにします。
- 公式訳のうち、ゲームの日本語フォントに無い漢字を含む4か所（「□」と表示される）は、表示できる書き方に置き換えます（例:「憧れ」→「あこがれ」）。
- ゲームがインストールされていない場合や、対応していないバージョンの場合は、何も変更せずにお知らせします。

音声は英語のままです。タイトルロゴなど画像に描かれた文字、日記の手書きの文字、オプション画面の見出しと「On / Off」など、ゲーム側で固定されている一部の表示も英語のままです。

## 使い方

1. [Releases](https://github.com/utausnskareshi/theredlantern-japanese-mod/releases) から `TheRedLanternJP-vX.Y.Z.zip` をダウンロードして展開します。
2. ゲームを終了した状態で `TheRedLanternJP.exe` を起動します。
3. 「日本語化する」を押します。
4. Steamからゲームを起動します。

元に戻すときは、もう一度ツールを起動して「元に戻す」を押してください。

初めて起動したときに「WindowsによってPCが保護されました」と表示された場合は「詳細情報」→「実行」を、「開いているファイル - セキュリティの警告」（発行元を確認できませんでした）と表示された場合は「実行」を押してください。このツールにはデジタル署名が無いため、インターネットから入手したファイルとして警告が表示されます。展開する前にZIPファイルのプロパティで「許可する」にチェックを入れておくと、表示されなくなります。

**動作環境**: Windows 10（1903以降）／Windows 11、Steam版 The Red Lantern。
Windowsに標準で入っている .NET Framework 4.8 で動くので、追加のランタイムは不要です。

**動作確認済みのゲーム**: Steam ビルド 20391034。

## 仕組み

PC版には、Steam版では使われていない日本語訳と日本語フォント（Noto Sans JP）が最初から入っています。
ただし起動時の言語が英語に固定されていて、切り替える設定がありません。このツールは次の2か所だけを変更します。

| ファイル | 変更内容 |
|---|---|
| `GameAssembly.dll` | 起動時の言語を指定している5バイトを書き換え、日本語で起動するようにする |
| `TheRedLantern_sw_Data\StreamingAssets\Flume\TheRedLantern_v001-Built.twig` | 日本語訳の無い行に補完訳を追記し、選択肢などの「既定の文言」を日本語訳にする（下記） |

台詞データ（`.twig`）で変更するのは次の3つだけで、英語の訳文やそのほかの内容は1バイトも変えません。

- 日本語訳の無い行に、補完訳を日本語として追記する。
- ゲームは選択肢などを表示するとき、言語の設定に関係なく各項目の「既定の文言」（英語）を使います。そのため、日本語訳がある項目は、既定の文言を日本語訳に置き換える（既定の文言が英語の訳文と同じ項目だけ）。
- 公式訳のうち、ゲームのフォントに無い漢字を含む4か所の語だけを、フォントにある文字で書き直す。

安全のための作り:

- 書き込む前に、両方のファイルが想定どおりの内容かを SHA-256 で確認します。一致しなければ何も変更しません。
- 台詞データの原本はゲームフォルダ内の `TheRedLanternJP_backup` にバックアップします。
- 「元に戻す」では、復元後のファイルが原本とハッシュ一致することまで確認し、バックアップを削除します。
- 「元に戻す」が台詞データを上書きするのは、その中身が「原本をこのツールが日本語化しただけのもの」と確認できたときだけです。ゲームの更新などで別の内容に置き換わっていた場合は、台詞データには触らず、プログラム本体だけを戻します。
- 画面の状態表示は、毎回ファイルの中身から判定します。Steamの「整合性の確認」などで元に戻った場合も正しく表示されます。
- ゲームの起動中や、Steamがゲームを更新中のときは書き込みません。ファイルが読み取り専用のとき、他のプログラムが使用中のときも、何も変更せずに止まります。
- 適用・復元の最中は、同じゲームに対する別の適用・復元（もう1つの画面やコマンドライン）を受け付けません。
- 処理の途中でPCの電源が落ちても、次に起動したときに「元に戻す」で原本に戻せます。

補完訳を使わず、公式の日本語訳だけを有効にしたい場合は、`translations` フォルダを削除してから「日本語化する」を押してください（公式訳の無い行は英語で表示されます）。

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| 「未対応のバージョン」と表示される | ゲームが更新されたか、ファイルが変更されています。Steamのライブラリでゲームを右クリック →「プロパティ」→「インストール済みファイル」→「ゲームファイルの整合性を確認」で正規の状態に戻せます。 |
| ゲームの更新後に英語へ戻った | 更新でファイルが置き換わったためです。対応版のツールで適用し直してください。 |
| 書き込みに失敗する | ゲームを終了してから実行してください。それでも失敗する場合は「管理者として実行」をお試しください。 |
| 「読み取り専用になっている」と表示される | メッセージに出ているファイルのプロパティを開き、「読み取り専用」のチェックを外してください。 |
| 「別の画面（またはコマンド）で処理中」と表示される | このツールをもう1つ起動していないか確認し、そちらの処理が終わってからやり直してください。 |
| 補完訳の欄に「使えません」と表示される | 補完訳ファイルの文字コードが UTF-8 ではありません。UTF-8 で保存し直してから、ツールを起動し直してください（そのまま続けると公式の日本語訳だけが有効になります）。 |
| 「台詞データはこのツールが書いた内容ではありません」と表示される | 日本語化した後で、ゲームの更新などにより台詞データが置き換わっています。「元に戻す」を押すとプログラム本体だけを戻します。その後は「整合性を確認」を実行してください。 |

ログは `%LOCALAPPDATA%\TheRedLanternJP\TheRedLanternJP.log` にあります。

## コマンドライン

画面を出さずに操作することもできます。

```
TheRedLanternJP.exe --status
TheRedLanternJP.exe --apply   [--supplement <ファイル> | --no-supplement]
TheRedLanternJP.exe --restore
TheRedLanternJP.exe --help
```

いずれも `--game-dir <フォルダ>` でゲームの場所を指定できます。終了コードは 0 = 正常、1 = 失敗、2 = 未インストール、3 = 未対応バージョンです。

## 開発者向け

```
dotnet build src\TheRedLanternJP\TheRedLanternJP.csproj -c Release
pwsh tools\build_release.ps1        # ビルド → dist\ に配布用ZIPを作成
```

- .NET SDK（8以降）があればビルドできます。ターゲットは .NET Framework 4.8 です。
- 新しいビルドのゲームに対応するには、`src\TheRedLanternJP\Core\KnownBuild.cs` にそのビルドのハッシュとパッチ位置を追加します（公式訳にフォントに無い文字があれば、`GlyphFixes` にその語の書き直しも）。

### 補完訳を直す・増やす

補完訳は `translations\ja_supplement.tsv`（UTF-8、`キー<TAB>日本語訳`）です。
UTF-8 として読めないファイル（Shift_JIS で保存し直したものなど）は、文字化けしたまま適用しないよう、ツールが読み込みを断ります。NUL などの制御文字を含む行は無視されます（改行・タブは `\n` `\t` と書きます）。

```
python tools\twig_tool.py stats                                   # ゲーム側の訳の有無を集計
python tools\twig_tool.py export-untranslated work\untranslated.tsv  # 未訳行を作業用に書き出す
python tools\twig_tool.py check translations\ja_supplement.tsv    # 補完訳を検証
```

守ること:

- **使える文字はゲームのフォントに入っている文字だけ**です（`translations\font_chars.txt`、1,311文字）。フォントは文字を追加できない設定になっていて、無い文字は「□」になります。`check` がこれを検査します。
- `<br>` や `<link="inputsprite">…</link>` などのタグ、行頭の `%?` `<>` はゲームが解釈する記号なので、原文どおりに残します。
- `export-untranslated` の出力にはゲームの英語原文が含まれます。作業用にとどめ、コミットや再配布はしないでください（`work/` は `.gitignore` 済み）。
